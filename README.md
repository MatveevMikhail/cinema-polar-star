# Сайт кинотеатра «Полярная звезда»

Контрольная работа по дисциплине «Разработка WEB-приложений».
Автор: Матвеев Михаил Андреевич.

## Запуск

1. Установить Node.js (LTS) с nodejs.org.
2. В папке проекта:
   ```
   npm install
   npm start
   ```
3. Открыть в браузере http://localhost:3000
   (если не открывается — http://127.0.0.1:3000).

Тестовый пользователь: `ivan@mail.ru` / `123`.

## Технологии

- Frontend: HTML, CSS, JavaScript (fetch).
- Backend: Node.js + Express.
- Данные: JSON-файлы в папке `data`.
